# 为什么要坚持开源工具

在 CODPEX，开源不是附加项，而是默认选项。

## 透明带来信任

用户可以看到代码如何运行，也能验证问题是否被认真修复。透明让工具更值得托付。

## 反馈让产品更好

来自真实场景的 Issue 与 Pull Request，往往比内部讨论更能指出产品的薄弱点。

## 长期主义

开源项目的使用寿命不依赖单一团队。社区参与让工具能够持续演进。

> 好的工具应该像基础设施一样存在：安静、可靠、随时可用。
