# 概览

Aurora.LoginAPI（A-Login API）是一个基于 **Flask** 的 **Python** 服务。它最初只是团队内部工具，后来决定开源。

它负责管理用户账号与登录认证，未来还会加入更多 API。

## 功能特性

- 邮箱验证码登录
- 邮箱 + 密码登录
- 使用 Redis 存储用户数据
- 通过 SMTP 发送验证邮件与欢迎邮件
- 可自定义的 HTML 邮件与页面模板

## 环境要求

| 要求 | 说明 |
|---|---|
| Git | 用于克隆仓库 |
| Python 3.11.3 | 已验证的运行时版本 |
| Redis | 存储用户数据与验证码 |
| SMTP 服务器 | 发送验证邮件与欢迎邮件 |
