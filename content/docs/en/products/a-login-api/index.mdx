# Overview

Aurora.LoginAPI (A-Login API) is a **Python** service built on **Flask**. It started as an internal tool for our team and was later open-sourced.

It manages user accounts and authentication. More APIs will be added in the future.

## Highlights

- Login with an email verification code
- Login with email and password
- User data stored in Redis
- Verification and welcome emails sent over SMTP
- Editable HTML email and page templates

## Requirements

| Requirement | Notes |
|---|---|
| Git | Used to clone the repository |
| Python 3.11.3 | The tested runtime version |
| Redis | Stores user data and verification codes |
| SMTP server | Sends verification and welcome emails |
